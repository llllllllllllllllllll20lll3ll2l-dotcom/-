# Disk Cleaner

Утилита для очистки дисков: **удаляется только то, что выбрал сам пользователь**.
Есть графический интерфейс (GUI) и консольный режим для автоматизации по расписанию.

## Возможности
- Правила очистки: папка + маски имён + расширения + минимальный размер + «старше N дней» + рекурсивно/нет.
- Предпросмотр найденного (размер, дата, путь), выделение галочками, удаление выбранного.
- Удаление **в корзину** (если установлен `send2trash`) или безвозвратно.
- Защита системных зон (`Windows`, `Program Files` и т.п.) — по умолчанию туда заходить нельзя.
- **Защита от самоуничтожения** — программа никогда не удалит собственные файлы, даже если вы случайно добавите папку проекта в правила с маской `*`.
- **Защита Python** — утилита не удалит интерпретатор Python (текущий и все найденные установки: `C:\Python*`, `Programs\Python`, conda/anaconda, Microsoft Store, `Python\bin`). Работает даже при включённом `--allow-protected`; корень диска (`C:\`) защитой не накрывается.
- Сохранение/загрузка наборов правил в JSON (профили).
- CLI-режим для Планировщика Windows.
- **Встроенный антивирус** — сигнатурная проверка (хеш + байтовые сигнатуры + эвристика) и **карантин** заражённых файлов вместо удаления. Опционально — быстрый скан через Windows Defender.

## Установка

### Вариант А — автоматически (рекомендуется)
Дважды кликните **`install.bat`**. Он сам:
1. Проверит, установлен ли Python 3.8+.
2. Если нет — установит его (через `winget`, а если его нет — скачает официальный установщик с python.org, ставится для текущего пользователя, добавляется в PATH и pip).
3. Обновит `pip` и поставит зависимости из `requirements.txt` (`send2trash` — для удаления в корзину).

После этого запускайте GUI двойным кликом по **`run.bat`**.

### Вариант Б — вручную
1. Установите Python 3.8+ (https://python.org, поставьте галочку *Add python.exe to PATH*).
2. (Опционально, для корзины) `pip install -r requirements.txt`

GUI работает на встроенном `tkinter`, ставить ничего не нужно.

## Запуск GUI
Двойной клик по **`run.bat`** или:
```
python disk_cleaner.py
```
Порядок работы:
1. Укажите папку, при желании маски/расширения/размер/возраст → **Добавить правило**.
2. **Сканировать**.
3. Отметьте галочками нужные объекты (клик по строке переключает ☑).
4. **Удалить выбранное** → подтверждение.

## Автоматическая чистка по расписанию
1. Отредактируйте **`example_rules.json`** под себя (пути, расширения, возраст).
   В `path` доступна подстановка `%USERNAME%`.
2. Проверьте, что будет удалено (ничего не удалится):
   ```
   python disk_cleaner.py --config example_rules.json --dry-run --list
   ```
3. Настройте **Планировщик заданий Windows** на запуск **`run_scheduled.bat`**
   (он выполняет `--execute --yes` и пишет лог в `clean_log.txt`).

### Ключи CLI
| Ключ | Действие |
|------|----------|
| `--config FILE` | файл правил (JSON). Без него запускается GUI |
| `--dry-run` | только показать, ничего не удалять |
| `--execute` | реально удалять |
| `--yes` | без подтверждения (для планировщика) |
| `--list` | вывести список найденных файлов |
| `--allow-protected` | разрешить системные зоны (опасно) |
| `--allow-self-delete` | разрешить удалить саму программу (самоуничтожение, опасно) |
| `--make-example` | создать пример правил в `--config` |
| `--no-av` | выключить антивирусную проверку |
| `--no-quarantine` | не помещать заражённые в карантин |
| `--delete-infected` | удалять заражённые вместо карантина (опасно) |
| `--signatures FILE` | доп. база сигнатур JSON |
| `--av-scan PATH` | проверить путь антивирусом и показать угрозы (без удаления) |
| `--defender` | с `--av-scan`: дополнительно вызвать Windows Defender |
| `--quarantine-dir DIR` | папка карантина (по умолчанию `<программа>/quarantine`) |
| `--quarantine-list` | показать содержимое карантина |
| `--restore NAME` | восстановить объект из карантина по имени |
| `--purge [NAME]` | безвозвратно удалить из карантина (без NAME — всё) |

## Формат файла правил (JSON)
```json
{
  "rules": [
    {
      "path": "C:\\Users\\%USERNAME%\\Downloads",
      "patterns": ["*"],
      "extensions": ["tmp", "log"],
      "min_size_kb": 1024,
      "max_size_kb": 0,
      "older_than_days": 30,
      "recursive": true,
      "include_dirs": false,
      "enabled": true
    }
  ],
  "use_recycle_bin": true,
  "allow_protected": false,
  "allow_self_delete": false,
  "follow_symlinks": false,
  "antivirus_enabled": true,
  "quarantine_enabled": true,
  "quarantine_dir": "",
  "allow_infected_delete": false,
  "signatures_file": ""
}
```
- `patterns` — glob-маски имён (`*.log`, `temp*`).
- `extensions` — без точки или с точкой, через список.
- `max_size_kb: 0` — без верхней границы.
- `older_than_days: 0` — возраст не проверяется.
- `include_dirs` — помечать подпадающие под маску папки (удаляются после файлов).
- `antivirus_enabled` — проверять найденные файлы антивирусом.
- `quarantine_enabled` — заражённые переносить в карантин, а не удалять.
- `quarantine_dir` — папка карантина (пусто = `<папка программы>/quarantine`).
- `allow_infected_delete` — `true`: удалять заражённые вместо карантина (опасно).
- `signatures_file` — своя база сигнатур (пусто = `virus_signatures.json` рядом).

## Встроенный антивирус и карантин

Модуль `antivirus.py` работает **без интернета** и не исполняет проверяемые файлы.

**Что детектирует:**
- **Хеши** (SHA-256) из базы `virus_signatures.json`.
- **Байтовые сигнатуры** — поиск hex-паттернов в теле файла (первые 4 МБ).
- **Эвристика**: двойные расширения (`invoice.pdf.exe`), EXE в Temp/Recycler, известные имена вымогателей.
- **EICAR** — официальный тест антивирусов (для самопроверки движка).

**Уровни:** `☣ MALWARE/TEST` — подтверждённая угроза (в карантин); `⚠ SUSPICIOUS` — только предупреждение (не блокирует удаление).

**Карантин:** заражённый файл физически переносится в папку `quarantine/`, переименовывается и записывается в `manifest.json` с исходным путём — его можно восстановить (`--restore`) или удалить навсегда (`--purge`).

**GUI:** колонка **«Угроза»** с подсветкой (красный — заражено, жёлтый — подозрительно), галка **«только угрозы»**, кнопка **«Отметить заражённые»**, опции **«Антивирус»** / **«Заражённые → в карантин»** и **«Открыть папку карантина»**.

**Проверка работы движка:**
```
python disk_cleaner.py --av-scan "C:\ПапкаДляПроверки"
```
Добавьте тест-файл EICAR (текст `X5O!P%@AP[4\PZX54(P^)7CC)7}$EICAR-STANDARD-ANTIVIRUS-TEST-FILE!$H+H*`) — движок его пометит.

**Windows Defender (опционально):**
```
python disk_cleaner.py --av-scan "C:\Папка" --defender
```

**Своя база сигнатур** (`virus_signatures.json`) — расширяется без правки кода:
```json
{
  "hashes": { "<sha256>": "ИмяУгрозы" },
  "signatures": [ { "name": "Имя", "pattern": "<hex байтов>" } ],
  "bad_names": [ "(?i)regex_по_имени" ]
}
```

## Важно про безопасность
- Без `--execute` ничего не удаляется.
- Системные папки защищены; обход — только осознанным `--allow-protected` / галкой в GUI.
- **Защита от самоуничтожения и Python включена всегда**: файлы самой программы и **все установки Python** (текущий интерпретатор, `C:\Python*`, `Programs\Python`, `Python\bin`, conda/anaconda, Microsoft Store) не удаляются даже при `--allow-protected`. Корень диска (`C:\`) защитой не накрывается, чтобы не ломать обычную очистку. Снять защиту можно только явным `--allow-self-delete` (или галкой в GUI с двойным подтверждением) — не используйте без крайней необходимости.
- Настоятельно рекомендуем первый прогон делать с корзиной и `--dry-run`.
